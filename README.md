# JP//SYSTEM — Portfolio

Portfólio pessoal desenvolvido para apresentar minha trajetória em tecnologia, experiência profissional, projetos, competências e formação.

A interface foi construída com uma identidade visual própria inspirada em sistemas e interfaces técnicas, buscando fugir do formato tradicional de portfólios e criar uma experiência simples, marcante e responsiva.

## Live

**Portfolio:**  
https://portfolio-steel-mu-fxevs4bqe5.vercel.app

## Sobre o projeto

O projeto foi desenvolvido do zero utilizando HTML, CSS e JavaScript, sem frameworks ou bibliotecas de interface.

Além de apresentar minhas informações profissionais, o próprio portfólio funciona como um projeto de front-end, explorando layout, responsividade, animações, microinterações e manipulação do DOM.

### Principais recursos

- Dark mode como tema principal
- Light mode opcional
- Português e Inglês
- Preferência de tema e idioma salva localmente
- Design responsivo
- Navegação com scroll suave
- Animações de entrada
- Microinterações
- Experiência profissional
- Projetos em destaque
- Stack de tecnologias
- Formação e certificações
- Currículo em PDF
- Links diretos para GitHub, LinkedIn e e-mail

## Projetos apresentados

### MedConform

Sistema acadêmico voltado à validação de OPMEs, desenvolvido em equipe durante o curso técnico.

O projeto trabalha com separação entre front-end e back-end, API REST, operações CRUD e persistência de dados.

**Tecnologias:** Python · Flask · SQLite · JavaScript · REST API
